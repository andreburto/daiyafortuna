# Counting Our Days Without Daiya

This is a simple static website that counts the number of days since Daiya's last tweet. It is hosted on AWS S3 and served through CloudFront.

The site is here: [https://daiyafortuna.mothersect.info/](https://daiyafortuna.mothersect.info/)

Daiya Fortuna can be found on X (formerly Twitter) at [https://x.com/Daiyafortuna](https://x.com/Daiyafortuna). More of her content can be found at [https://beacons.ai/daiyafortuna](https://beacons.ai/daiyafortuna).
